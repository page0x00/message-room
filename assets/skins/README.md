# Scene assets

Six independently generated photographic backgrounds for the 2.4.1 reference-UI skin revision. The application renders its own interactive DOM; these files contain no labels or controls. Generation briefs are retained in `prompts.json`.

| File | Skin |
| --- | --- |
| ins-day.webp | Ins · 日间 |
| ins-night.webp | Ins · 夜间 |
| warm-day.webp | 暖色 · 日间 |
| warm-night.webp | 暖色 · 夜间 |
| rain-night.webp | 雨窗 · 夜景 |
| moon-glass.webp | 月光 · 玻璃 |

1536 × 1024 RGB, WebP quality 86. CSS positions the scenes responsively; foreground paper, records, controls and text are HTML/CSS.
