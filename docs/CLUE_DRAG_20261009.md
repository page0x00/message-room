# 线索板缩放与拖动范围修复（2.7.3）

正式站：https://page0x00.github.io/message-room/

## 问题与处理

- 原先按未缩放画布尺寸限制卡片位置。缩到 50% 后，背景仍铺满面板，卡片却只能停在中央缩小后的区域。
- 现在把实际可见面板反算到画布坐标，再按卡片实际尺寸和旋转后的边缘限制拖动。缩放改变卡片大小，可见面板四角仍可放置卡片。
- 按抓取位置计算移动，平移或缩放后仍跟随手指；较大卡片允许在自身两端之间移动。
- 扩展画布范围包含拖到原画布以外的卡片；向内拖动不再收缩已经使用的空间，避免松手时画面回弹。
- 沿用旧位置格式，允许保存超出原画布的坐标。重新打开时适配已保存的展开布局；连线继续跟随位置。双指缩放仍会取消尚未完成的单指拖动。
- 更新资源版本为 2.7.3，避免浏览器继续引用旧模块。无数据库迁移、主题结构或样式调整。

## 验证

- 新增 `npm run test:clue`：5 项检查，覆盖便签与照片在 50% 时拖至可见面板四角、50% → 113% → 50% 双指缩放、平移后的跟手拖动与连线、位置保存与重开、手机/平板/横屏及侧栏收起后的拖动。
- 更正旧触摸用例：以可见面板边缘为断言，不能再用缩小后的画布边缘代替。
- 回归通过：`npm run test:touch` 7 项、`npm run test:reference` 5 项、`npm run test:memory` 4 项、`npm test` 64 项；`npm run check` 通过。

浏览器测试使用 Chromium 触屏模拟和隔离的后端响应，没有修改真实房间数据。
