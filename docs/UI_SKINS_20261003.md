# 统一图三排版 · 2.4.2

本轮沿用 `update/relationship-space-20261001`，修正 2.4.1 中浅色主题、雨窗与月光使用不同构图的问题。六套主题现在使用同一个 DOM 和 `scene-layout.css`；主题选择器只声明材质、光线和颜色变量，不再决定布局。

| 图三区域 | 实际功能与行为 |
| --- | --- |
| 左侧窄导航 | 首页、对话、记忆、日程、信箱、更多；底部六个主题色块 |
| 顶部标题与工具 | 诗句、搜索已载入的留言和功能、通知设置、本地时间 |
| 左侧主卡片 | 根据本地时间问候；点“留一封信”进入原聊天；切换首页保留草稿、消息节点与音乐 |
| 右上音乐 | 复用现有音频、播放 / 暂停、上一首 / 下一首、进度、播放顺序、喜欢与歌曲导入 |
| 右下今日计划 | 真实待办与完成数；勾选和撤销仍由原控制器按成员权限写回 |
| 下方四个入口 | 回忆墙、一起打卡、共同活动、小小陪伴；不新增演示功能或示例数据 |
| 右下横幅 | 打开现有回忆胶片放映室 |

桌面按图三的主卡片与右列比例、上下对齐、窄侧栏和悬浮卡片组织；1180 × 630 和 1024 × 600 的平板横屏仍保留完整结构。手机按相同顺序纵向滚动，并将六个导航入口固定在底部。功能页沿用原侧栏；手机功能页覆盖整屏。一起听、便签 / 线索 / 唱片墙、荷包和胶片内部功能保持。

摄影层、玻璃透光层、边缘高光、内侧细线与投影分别处理，六套色系使用相同尺寸与圆角。旧版两个主题专用的构图与高度隐藏条件已经删除。

首页不会把后台到达的消息当作已阅读；回到对话后恢复原未读处理。信箱列表作为可收起面板打开，不会因切换导航而断开当前房间或重建播放器。版本参数统一更新为 2.4.2，避免旧 CSS 与新布局混用。没有新增数据库迁移。
