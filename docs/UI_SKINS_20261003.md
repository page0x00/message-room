## 素材

- `assets/skins/*.webp`：本次独立生成的六幅窗景，仅提供材质和背景，没有把参考 UI 整张嵌入页面。原始文字需求保存在同目录 `prompts.json`。发布图均为 1536 × 1024，WebP 质量 86，六张合计约 1.04 MiB。
- `assets/fonts/mailbox-wenkai.woff`：霞鹜文楷轻便版 v1.522 Regular 的常用简体中文子集，字体内部名称已改为 Mailbox WenKai。支持 GB2312 字符及当前 UI 文本，其他字回退到系统字体。许可证：`assets/fonts/OFL.txt`。
- 字体上游：[LXGW WenKai Lite](https://github.com/lxgw/LxgwWenKai-Lite)，[v1.522](https://github.com/lxgw/LxgwWenKai-Lite/releases/tag/v1.522)。

## 验证

浏览器测试拦截 Supabase 请求，使用隔离夹具，没有访问生产数据库。真实数据的服务端权限和支付规则没有改动。检查包括六种主题及五类屏幕尺寸、聊天草稿保持、音乐播放 / 歌单 / 歌词 / 精确时长、回忆翻面 / 拖动 / 惯性 / 光照、胶片媒体 / 倒带 / 场景跳转、日常记录及荷包存取 / 假条 / 冷静期。

本轮 `npm run check`、44 项逻辑 / Edge 测试，以及 28 项浏览器流程（space 3、daily 7、music 6、memory 4、film 5、skins 3）均通过。逐张检查实际渲染后修正了大屏宽度、背景裁切、顶部歌词遮挡和纸卡对比度。

`npm run test:skins` 另检查全部背景与字体能实际加载、横屏播放控制和待办写回，以及六套皮肤的渲染截图。截图位于被 Git 忽略的 `test-results/skin-*.png`，没有把演示记录写入产品。

当前版本只更新前端皮肤、入口与相关回归测试，不需要新增数据库迁移。部署状态由现有 GitHub Pages 与 Supabase 项目配置决定。
