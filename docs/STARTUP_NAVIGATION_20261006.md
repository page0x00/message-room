# 正式站入口与主题启动修复（2.7.2）

正式站： https://page0x00.github.io/message-room/

## 根因与处理

- 根地址没有 room 参数时，旧逻辑未恢复本机上次访问的房间，对话、记忆、日程、更多均静默跳到信箱。现在按登录账号恢复明确访问过的本机房间，不从云端成员列表任意选取房间。主动退出房间或清空记录后不自动恢复。
- 首次使用或没有可恢复记录时，显示选择房间的说明，保留最后点击的目标；选好房间后继续进入该页面。更多和 API 设置无须先选房间。
- 登录较慢时，以用户最后一次导航为准。用户主动打开信箱、首页或更多后，后台响应不能覆盖该选择。
- 旧信箱布局原本会在 JS 构建当前界面之前显示。现在先按已保存主题显示启动界面，控制器就绪后才显示可交互内容。初始化不等待身份验证、云端列表或媒体下载。
- 主题在首屏脚本中只解析一次，兼容旧版本存储与损坏值；界面初始化沿用这个结果。加载失败或持续较慢时提供重新加载按钮。
- 所有应用资源版本升级为 2.7.2，避免浏览器继续混用旧模块。
